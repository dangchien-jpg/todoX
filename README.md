# todoX
todoX is a full-stack Todo application that helps users manage daily tasks efficiently.  
The app allows users to create, update, delete, and filter tasks by date and status with a clean and responsive UI.

**Live Demo**: https://todox-5ya6.onrender.com 

## 🚀 Features
- Add new tasks
- Edit existing tasks
- Delete tasks
- Filter tasks by date
- Filter tasks by status (completed / active)
- Fully responsive UI (mobile & desktop)
- Pagination
- RESTful API integration

## 🛠 Tech Stack
### Backend
- NodeJS, ExpressJS
- MongoDB Atlas
### Frontend
- ReactJS, Tailwind CSS, Axios
### Tools
- Git / GitHub
- Postman
### Deloy 
- Render

## ⚙️ Environment Variables
Create `.env.development` and `.env.production` files in the backend folder.
### Example:

```env
PORT=5001
CONNECT_STRING_DATABASE=your_mongodb_atlas_connection_string
NODE_ENV=development
```
## ⚙️ Installation & Run
### Backend
```bash
cd backend
npm install
npm run dev
```
### Frontend
```bash
cd frontend
npm install
npm run dev
